## Instrucciones para Verificar Videos

1. **Abrir URL:** https://www.youtube.com/embed/[VIDEO_ID]
2. **Verificar que carga:** No debe mostrar "Video no disponible"
3. **Verificar acceso:** Debe permitir embebido (no bloqueado)
4. **Verificar idioma:** Confirmar que coincide con audiencia objetivo

## Solución de Problemas con Videos

### Si un video no se visualiza:

1. **Verificar enlace directo:** https://www.youtube.com/watch?v=[VIDEO_ID]
2. **Comprobar restricciones:** Algunos videos no permiten embebido
3. **Buscar alternativa:** Usar la lista de videos de respaldo
4. **Actualizar ID:** Reemplazar en modules-data.js
